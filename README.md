# Bird Nest

Anthony's day, step by step. An installable app (PWA), not a Claude artifact.
Head (Clearhead) + Body (Bird Fitness) on one River timeline. Money joins in Phase 6.

- The plan: `BUILD.md`
- Where we are: `PROGRESS.md`
- Why things are the way they are: `DECISIONS.md`
- Parking lot: `IDEAS.md`

## Run it

```
npm install
cp .env.example .env   # then fill in the Supabase URL and publishable key
npm run dev
```

`npm test` runs the checks. `npm run build` makes the app in `dist/`.
